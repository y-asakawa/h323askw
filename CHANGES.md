# Change Log

This file documents modifications made by H323ASKW to the CallGen323
Original Code, as required by Section 3.3 of the Mozilla Public License
Version 1.0.

H323ASKW is derived from CallGen323. The Initial Developer of the
Original Code is Benny L. Prijono.

## 2026

* Continued development of the Qt 6 based H.323 video client.
* Added or improved audio and video device handling.
* Added compatibility fixes for H323Plus and PTLib.
* Improved macOS application bundle packaging and runtime dependency handling.
* Added repository documentation, security policy, automated checks, and
  third-party license notices.

## 2025

* Added the Qt 6 user interface for video display, call controls, media device
  selection, audio-level display, and local preview handling.
* Added H.239 content-sharing support and local and remote video view handling.
* Added recording support and SpeexDSP-based audio processing.
* Added macOS camera, microphone, local-network, and firewall-related handling.

## 2024

* Derived H323ASKW from CallGen323.
* Began adapting the original call generator into a macOS Apple Silicon
  H.323 audio and video client.
* Added the initial macOS ARM64 build and application structure.
